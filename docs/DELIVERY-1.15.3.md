# EhViewer Hycnyl 1.15.3

包名 `moe.hycnyl.ehviewer`，版本码 `180067`，Android 8.0+。沿用 1.15.2 的签名和数据格式，可直接升级。开发基线为 `2329425ed345a1f6d8df6666f50c8610ac6650b5`，核心修改由主 Codex 完成，未委派子代理。继续由 GitHub Actions 直接发布正式版，提供 universal、arm64-v8a、armeabi-v7a、x86_64、x86。

## 自定义阅读缓存

设置 → 高级 → 阅读缓存大小，保留原有 320–5120 MB 选项，新增“自定义”。输入单位为 GB，支持小数，数值必须大于等于 5；无效输入时确认按钮不可用。输入窗口只有标题、数值、GB 单位和确认／取消按钮，没有额外说明小字。保存后使用原版重启提示，重启生效。

改造前核对了当前 Coil 3.3.0 的实际实现：`DiskCache.Builder.maxSizeBytes`、`DiskLruCache.maxSize` 和总大小计数均为 Long；指定绝对字节容量后，不再走百分比容量裁剪。原来的 5 GB 限制来自 EhViewer 自身的 `coerceIn(320, 5120)`，不是缓存库的上限。

本版保留 `read_cache_size_2` 的 Int MB 配置，不迁移或清空缓存，只移除上限裁剪，并先转 Long 再计算字节。自定义 GB 换算到原有 MB 精度，数值过小、无效或超出原配置可表示范围时不保存。缓存仍写入原来的磁盘目录；不会按所设容量预分配同等大小的文件或图片内存，阅读器的解码内存限额也未改。磁盘实际可用空间和 Android 对缓存目录的回收机制仍然适用，没有为此增加权限或新的存储策略。

选择重启生效是因为原版 `imageCache` 按进程惰性创建；复用原版重启流程即可应用新容量，无须重建正在使用的图片加载器或修改阅读器。

## 下载列表入口

下载列表、网格中的普通点击改为与收藏页相同的画廊详情入口。封面点击原本就能进入详情，本次保留；多选、暂停／继续、随机阅读等操作不改。

可行性核查：原版详情页接收下载项已有的画廊信息，并立即显示“阅读”按钮；本地下载存在时，详情加载失败或画廊已下架也仍能打开本地阅读。此次只替换共用点击回调，不修改详情请求、阅读器和下载状态。查看详情后比直接阅读多一次点击，这是本次明确要求的入口行为。

## 文案和语言

简体中文按用户给出的文字替换功能说明、两种格式提示、完成提示和导出中提示。散图提示为“推荐选择此项”，CBZ 提示为“有一定破坏性”。两种格式成功加入下载列表后共用完成文案；实际未能登记或写入失败时仍保留对应错误信息。导出进度引用原有文件计数，不更改文件导出流程。
