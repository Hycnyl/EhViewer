包名 `moe.hycnyl.ehviewer`，版本码 `180065`，Android 8.0+。本次是 1.15.0 的兼容性修复和界面改进，延续 FooIbar 1.14.6 (`0195f1c9b8f9397e635c84ce14735ba2a2aae4c8`) 的版本体系。仅以当前 Hycnyl 仓库 `10c43f3ed1906945ef85ae5ff58d400d980032a9` 为开发基线，核心代码由主 Codex 代理亲自实现，未使用子代理。

安装包提供 universal、arm64-v8a、armeabi-v7a、x86_64、x86，发布在 [Hycnyl/EhViewer Releases](https://github.com/Hycnyl/EhViewer/releases)。保持 1.15.0 的包名和仓库原有测试签名，可直接升级该 fork；原 FooIbar 包的私有缓存仍不能由新包直接读取。

实际预发布：[v1.15.1-pre.4](https://github.com/Hycnyl/EhViewer/releases/tag/v1.15.1-pre.4)。[GitHub Actions #4](https://github.com/Hycnyl/EhViewer/actions/runs/40455879012) 构建成功，五个公开 APK 的 SHA-256 与本地校验产物逐一相同。包信息、文件大小、散列及两套测试结果见 [机器可读验证记录](validation-1.15.1.json)，发布页同时提供 `SHA256SUMS.txt`。

## 本次修复

- 独立救援 CBZ 继续使用 `gid.cached-partial*.cbz`，不充当完整下载。原生散图按全局“保存为 CBZ”设置进入原下载目录或持久临时目录。用户随后切换设置时，普通下载先安全复制到本次下载实际使用的目标目录，再认可页面命中；原位置文件保留。
- 下载读取页面、跳过已有页面和实际写入位置使用相同目录语义；文件路径分别建索引，避免两边同名页面相互遮蔽。继续利用有效 Coil 缓存，保留普通阅读对两个原有目录的查找。
- 安全复制复用救援提交流程：临时文件、长度/CRC 校验、提交标记、发布后验证。故障或取消只回滚本次未提交文件；已有页面和源文件不覆盖。元数据冲突保留原文件并报告接管结果。
- 长导出只隔离同 GID。其他画廊的单项、批量、全部下载请求无需等导出结束；保持原队列顺序及自动推进。下载请求之间仍用原有短序列化入口，导出 I/O 不持有它。门控登记锁只保护计数，不执行 I/O 或挂起；状态检查在登记后完成。蜘蛛 root Job 直到 **completed** 才解除登记，取消但仍在收尾的任务继续阻止同 GID 救援。
- `.ehviewer` 必须匹配 GID 和 Token 才能贡献可信页数；XML 还须具有匹配画廊的站点 URL。外来或身份冲突元数据不参与真实总数推断。正常归档 `gid.cbz` / `gid.zip` 的识别、完成判断和整理逻辑保持原状。

## 总页数未知仍可从下载列表阅读

研究原版 `.ehviewer` 后确认：它存储蜘蛛页数、身份和 pToken 等本地阅读准备数据；阅读准备要求 `pages > 0`。单纯不写页数会阻碍失效画廊从下载列表打开，因此不能直接跳过本地登记。

本版将“缓存可阅读范围”和“画廊真实总数”分开：未知时 `.ehviewer` 中 `pages=0`，新增可选字段 `cachedPageCount` 保存原页码上界；`ComicInfo.xml` 的 PageCount 与数据库画廊总数均保持 0。只有读取这种救援元数据时，提供临时的阅读范围，阅读器仍使用原页码，关闭后不会把上界回写成真实总数。旧的正常元数据不经过这种转换。

原生文件和阅读元数据安全可用后，下载项登记为原有 `STATE_NONE`，可以离线打开已有页。真实总数未知的这类条目请求普通下载时，会提示先补充可信总数，防止普通完成判断把缓存上界当成全本；取得匹配身份且覆盖已有范围的真实总数后可以正常下载。缺失页仍按原阅读器行为显示，不生成占位图片。救援本身不联网。

示例：只找到第 3、8 页时，文件仍为 `00000003.*`、`00000008.*`；本地阅读范围为 1–8，总数显示“未知”，不会报告“8 页全本”。已有健康的旧版元数据不会被本次导出覆盖；无法证明来源的旧版估算页数也不做自动改写。

## 界面和关于页面

“导出已缓存页面”改用随主题变化的统计卡、醒目页数、离线/页码范围/数据大小标记和格式选择卡；输出位置可选中复制，警告可以展开。未知总数提供 2,000 / 10,000 / 50,000 的显式本地扫描上界，扫描和导出均可取消。

关于页沿用原版作者样式，将 Foolbar 划去并添加 Hycnyl 链接。源码、最新版本、检查更新统一指向 Hycnyl 仓库；更新检查兼容只有预发布的仓库，CI 通道对应本仓库 `cache-rescue.yml`。下载更新优先匹配设备 ABI，再退回 universal，不会选中校验文件或其他架构。相同已装预发布不会反复提示更新，也不会降级。公开仓库更新不再携带原代码内的第三方固定认证信息。

## 已确认的取舍与限制

- 按用户确认采用后续任务书目录规则，替代 1.15.0 的“CBZ 救援原生副本一律写 temp”。
- P2 按用户确认暂缓。已有同画廊阅读器或蜘蛛任务仍在收尾时拒绝救援并提示先关闭/等待；救援期间新开的同 GID 阅读器等待完成，其他 GID 不受影响。不改阅读器核心状态机。
- SAF 内容提供器故障、不同厂商设备的交互和新界面尚未做真机验收；本地集成用例使用真实文件描述符，但不能代替所有 SAF 提供器。无硬件加速模拟器环境，本次不为外观另做冗长环境搭建。
- 现有元数据若不能覆盖本次发现的页号或身份不符，保留原文件并报告原生接管未完成；已验证提交的散图和独立快照仍会保留。
- 不改原版画廊网络请求、正常完成条件、完整归档命名、数据库 schema，不增加权限；保留原 LICENSE/NOTICE 和作者版权。
